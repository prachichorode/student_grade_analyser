# Student Grade Analyzer Using Python

## 1. Project Introduction

The Student Grade Analyzer is a beginner-level Python project developed to analyze students' academic performance.

This application accepts student details and subject-wise marks, calculates total marks and average percentage, assigns grades, and determines whether a student has passed or failed.

It also provides class statistics, including the highest average, lowest average, overall class average, and the number of passed and failed students.

## 2. Project Objectives

- Develop a Python application to analyze student marks.
- Calculate total marks and average percentage.
- Assign grades based on student performance.
- Determine Pass or Fail status.
- Generate student performance reports.
- Analyze the performance of multiple students.

## 3. Features

1. **Student Details:** Accept student name and roll number.
2. **Marks Input:** Accept marks for five subjects.
3. **Total Calculation:** Calculate the total marks.
4. **Average Calculation:** Calculate the average percentage.
5. **Grade Calculation:** Assign grades based on average marks.
6. **Pass/Fail Status:** Determine student results.
7. **Performance Report:** Display complete student information.
8. **Class Statistics:** Display class average, highest average, lowest average, and pass/fail counts.

## 6. Grading System

| Average Marks | Grade |
|---|---|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 40 - 59 | D |
| Below 40 | F |

**Passing Criteria:** A student must score at least 35 marks in every subject to pass.

## 8. How to Run the Project

**Step 1:** Install Python on your computer.

**Step 2:** Open the project folder in Visual Studio Code.

**Step 3:** Open the terminal.

**Step 4:** Execute the following command:

```bash
python main.py
```

**Step 5:** Select an option from the menu.

- Option 1: Add Student
- Option 2: Display All Students
- Option 3: Class Statistics
- Option 4: Exit
